# Yola Gel

**Yola Gel** is a strategy and knowledge-based 2D top-down traffic education game where players place traffic signs in the correct locations to prevent accidents and maintain a safe traffic flow.

Players must analyze each traffic scenario, learn the functions of different road signs, and place the appropriate signs before starting the simulation. Correct decisions allow vehicles to move safely, while incorrect sign placement may lead to traffic accidents and failure.

## About the Game

Traffic safety depends on understanding road signs and using them correctly.

In **Yola Gel**, players are presented with different traffic scenarios containing empty sign placement areas. Before starting the simulation, the player must examine the road layout, consider the movement of the vehicles, and place the correct traffic signs in the appropriate locations.

After completing the placements, the player starts the scenario and observes the result.

If all signs have been placed correctly, the vehicles complete their routes without an accident and the level is successfully completed. Incorrect placements may disrupt the traffic flow, cause an accident, and demonstrate the consequences of improper road sign usage.

Through its puzzle and strategy-based gameplay, Yola Gel aims to make learning basic traffic signs more interactive and engaging.

## Gameplay

The main objective is to prevent traffic accidents by placing the correct traffic signs in each level.

Players can:

* Analyze different traffic scenarios
* Select traffic signs from the available interface
* Place signs in designated areas
* Learn the meaning and purpose of traffic signs
* Start the traffic simulation
* Observe vehicle movements and traffic flow
* Identify incorrect sign placements
* Complete levels without causing an accident

Each level requires observation, logical thinking, and an understanding of basic traffic rules.

## General Rules

* Traffic signs must be placed according to the situation presented in the level.
* Each sign can only be placed in suitable sign placement areas.
* Players can review information about traffic signs through the information menu.
* Correct sign placement creates a safe traffic flow.
* Incorrect sign placement may cause vehicles to crash.
* A level is completed when all vehicles safely finish the traffic scenario.

## Controls

Yola Gel is designed for both mobile devices and computers.

| Action                    | Mobile                     | PC                           |
| ------------------------- | -------------------------- | ---------------------------- |
| Select a traffic sign     | Tap the sign               | Left Mouse Button            |
| Place a traffic sign      | Tap the placement area     | Left Mouse Button            |
| Use interface buttons     | Tap the button             | Left Mouse Button            |
| Start the simulation      | Tap the start button       | Click the start button       |
| Open the information menu | Tap the information button | Click the information button |
| Pause the game            | Tap the pause button       | Click the pause button       |

The controls are primarily based on touch interaction and on-screen interface buttons. Mouse input provides the same interactions when the game is played on a computer.

## Installation

Download or clone the repository:

```bash
git clone https://github.com/CantheDEV/Yola-Gel.git
```

Open **Unity Hub**.

Select **Add Project from Disk**.

Choose the downloaded project folder.

Open the project using the appropriate Unity version.

Open the main game scene located inside the `Assets` folder.

Press the **Play** button in the Unity Editor.
